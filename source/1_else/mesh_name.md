不同网格类型对应的英文如下：

- **三角形网格**：Triangular mesh / Triangle mesh  
- **四面体网格**：Tetrahedral mesh / Tetrahedron mesh  
- **六面体网格**：Hexahedral mesh / Hexahedron mesh  
- **四边形网格**：Quadrilateral mesh / Quad mesh  
- **棱柱网格**：Prismatic mesh / Prism mesh  
- **金字塔形网格**：Pyramidal mesh / Pyramid mesh  
- **多边形网格**：Polygonal mesh  
- **多面体网格**：Polyhedral mesh
